# The Dugout - Deliverable 2

## Project Description
The Dugout is a fantasy cricket league project developed using Python and FastAPI.

## Features
- Player and team management
- Fantasy team validation
- Exception handling
- CSV and JSON file handling
- Cricket match reports
- REST API

## Installation

```bash
pip install -r requirements.txt
```

## Start the API Server

```bash
uvicorn dugout.api:app --reload
```

## API Documentation

http://127.0.0.1:8000/docs

## Run the Programs

```bash
python main.py
python match_report.py
```
